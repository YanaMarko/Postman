# Тестирование REST API при помощи Postman (Chuck Norris API & Google Maps API)

Учебный проект для отработки навыков ручного и автоматизированного тестирования REST API. 

## 🚀 Стек технологий и инструменты
* **Инструмент тестирования:** Postman (Web Client)
* **Язык автотестов:** JavaScript (Postman Sandbox)
* **Формат данных:** JSON
* **Авторизация:** API Key (для Google Maps)

## 🛠 Что было протестировано

### 1. Chuck Norris API (api.chucknorris.io)
Использовался для базовой отработки HTTP-методов и написания простых скриптов.

**Проверки:**
* **Позитивные сценарии:** Получение шутки по слову, получение списка категорий шуток
* **Негативные сценарии:** Получение шуток из несуществующей категории

### 2. Google Maps API (maps.googleapis.com)
Использовался для симуляции работы с реальным enterprise-сервисом, требующим авторизации и передачи сложных параметров.

**Проверки:**
* **Позитивные сценарии:** Добавление новой локации, проверка новой локации, удаление локации
* **Негативные сценарии:** Проверка локации к несуществующим id, обновление локации с несуществующим id, удаление локации с несуществующим id

## ⚙️ Инструкция по запуску тестов
1. Установите [Postman](https://www.postman.com/).
2. Скачайте файлы данного репозитория:
3. В Postman нажмите кнопку **Import** и выберите скачанные файлы.
4. Для запуска всех автотестов разом используйте встроенный инструмент **Collection Runner** внутри Postman.
